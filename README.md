# Bananerna Studios submission for META Game Jam 2026
## How to add project to Godot
### 1. Get REPO
1. DM me your github username
2. Check mail for invite to this repository and accept it
### Using Github Desktop (what I'm using):
3. Download [Github Desktop](https://desktop.github.com/download/)
4. Open it
5. Click on File -> Clone Repository
6. Search for `MineSwe/Bananerna-Studios-META-Game-Jam-2026`
7. Make the local path where you want the project to be
8. Click clone
### Using commandline:
3. cd to the path where you want it to be
4. Type `git clone git@github.com:MineSwe/Bananerna-Studios-META-Game-Jam-2026.git`
### Download and connect to Godot:
1. Download [Godot](https://godotengine.org/download/windows/)
2. Click on Import and go to `*repopath*/Godot Project files/meta-game-jam-26`
3. Click on Select this folder
4. DONE!
## How to contribute
1. Goto [the kanban board](https://github.com/users/MineSwe/projects/1)
2. Add a idea using the + icon, typing a issue name and pressing `Create new issue`
3. Create and connect to a branch using either Github Desktop branch buttons or `git branch 'branch-name'` and `git checkout 'branch-name'`
>*note: make names such as "player-movement", "level-1" or something like that*
4. Make how many commits & pushes you'll like until you're done with your task
5. Make git pull request [here](https://github.com/MineSwe/Bananerna-Studios-META-Game-Jam-2026/pulls) and close the issues by typing `fixes #'issue-number'` in the description
